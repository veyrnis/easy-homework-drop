# easy-homework-drop

基于 Python Flask 的轻量级局域网作业收集系统。

## 项目简介

这是一个纯本地运行的单文件 Web 应用，用于解决局域网内（如机房、教室）收集学生作业时，U 盘交叉感染病毒、网络传输缓慢、文件命名混乱等问题。

## 核心特性

- 免 U 盘，局域网内通过浏览器直接访问
- 文件强制按 `学号_姓名_文件名` 格式自动重命名
- 限制单文件最大 20MB，严格过滤可执行文件后缀
- 自带现代 UI（Glassmorphism 风格），支持深色模式与拖拽上传
- 提供一键打包脚本，可生成独立 `.exe` 发布包

## 快速开始

1. 环境准备：安装 Python 3.8+。
2. 编译打包：双击运行 `build.bat`，自动安装依赖并打包出 `作业收集.exe`。
3. 启动服务：运行 `作业收集.exe`，终端会打印局域网访问地址（如 `http://192.168.1.100:8080`）。
4. 接收作业：确保学生设备与老师电脑在同一网络下，浏览器访问上述地址即可。

默认管理密码为 `admin888`，请进入网页「设置 -> 老师模式」及时修改。
